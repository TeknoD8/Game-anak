# Main & Belajar Anak

Game edukasi berbahasa Indonesia untuk anak, dimainkan langsung di browser.

- **3–5 tahun**: Warna, Hitung, Hewan, Bentuk
- **5–8 tahun**: Membaca, Berhitung, Jam, Pola
- **8–11 tahun**: Kali & Bagi, Pecahan, Ejaan, Pengetahuan

Harap didampingi orang tua saat bermain.

Main di: https://teknod8.github.io/Game-anak/
